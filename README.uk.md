# WiClip — історія буфера обміну для Windows

[English](README.md) · [Русский](README.ru.md) · **Українська**

[Завантажити інсталятор](https://github.com/tyaglovsky/wiclip/releases/latest)

Менеджер буфера обміну для Windows 10 / 11 / Server 2016+. Живе в треї, за гарячою
клавішею показує вікно з останніми скопійованими записами, а обраний запис вставляє
в активне вікно.

Інтерфейс програми — **англійською та російською**: мова береться з налаштувань Windows
або задається вручну. Українська локалізація інтерфейсу поки не зроблена.

## Можливості

- **Вікно історії за гарячою клавішею** (типово `Ctrl+Shift+V`) — відкривається біля курсора.
- **Текст, зображення та списки файлів** із буфера обміну.
- **Пошук** по історії (просто почніть друкувати), швидкий вибір `Alt+1…9`.
- **Закріплення** потрібних записів — вони не витісняються і завжди зверху.
- **Автовставка**: обраний запис копіюється в буфер і надсилається `Ctrl+V` у те вікно,
  яке було активним до виклику WiClip.
- **Приватність**: буфер, позначений менеджерами паролів (`Clipboard Viewer Ignore`,
  `ExcludeClipboardContentFromMonitorProcessing`, `CanIncludeInClipboardHistory`),
  до історії не потрапляє; окремо є чорний список процесів.
- **Тема** світла/темна/як у системі, коректно працює на моніторах із різним DPI.
- **MSI-інсталятор** із тихим встановленням, оновленням поверх та автозапуском.

## Гарячі клавіші у вікні

| Клавіші | Дія |
|---|---|
| `Ctrl+Shift+V` | відкрити вікно (налаштовується) |
| одинарний клік | скопіювати запис у буфер, вікно лишається відкритим |
| подвійний клік | вставити в активне вікно |
| ↑ / ↓, PgUp / PgDn | переміщення списком |
| `Enter` | вставити в активне вікно |
| `Ctrl+Enter` | лише скопіювати в буфер, без вставки |
| `Alt+1…9` | швидкий вибір запису за номером |
| `Ctrl+P` | закріпити / відкріпити |
| `Shift+Delete` | видалити запис з історії |
| `Esc` | закрити вікно |

Усе, що набирається з клавіатури, потрапляє в рядок пошуку.

## Збірка

Потрібні **Windows**, **.NET SDK 8.0+** та **WiX 5**:

```powershell
dotnet tool install --global wix --version 5.0.2
```

Версію вказувати обовʼязково: WiX 6 і новіші вимагають прийняти
[Open Source Maintenance Fee EULA](https://wixtoolset.org/osmf/) і без цього падають
з помилкою `WIX7015`. Якщо версія 6/7 вже стоїть — `dotnet tool uninstall --global wix`,
потім команда вище.

Далі з кореня репозиторію:

```powershell
.\build.ps1
```

Результат: `dist\WiClip-1.0.1-x64.msi` і тека `publish\x64` з готовою програмою.

Корисні параметри:

```powershell
.\build.ps1 -Version 1.2.0 -Arch x64 -Culture ru-RU
```

- `-SkipMsi` — зібрати лише exe, без інсталятора.
- `-Arch x86|arm64` — інша розрядність.
- `-Culture en-US` — мова інсталятора (`en-US` або `ru-RU`; у самій програмі є обидві).

`build.ps1` навмисно написаний лише латиницею. Windows PowerShell 5.1 читає скрипти без
BOM у системному кодуванні, тож не-ASCII символи в коді ламали б розбір (`UnexpectedToken`),
якби файл не зберігався як UTF-8 з BOM. ASCII знімає це питання — нові коментарі та
повідомлення теж пишіть англійською.

Програма публікується **self-contained**: .NET Desktop Runtime на цільовій машині
не потрібен, що зручно для серверів і закритих контурів. Ціна — розмір MSI близько
50–90 МБ. Якщо рантайм на машинах уже стоїть, у `src/WiClip/WiClip.csproj` можна
поставити `<SelfContained>false</SelfContained>` — пакет стане ~1 МБ.

## Встановлення

Подвійний клік на MSI — майстер сам запитає, встановлювати **для всіх користувачів**
чи **лише для мене**:

| Режим | Куди | Права | Автозапуск |
|---|---|---|---|
| Для всіх користувачів | `C:\Program Files\WiClip` | потрібен адмін | `HKLM\...\Run` — у будь-якого користувача машини |
| Лише для мене | `%LocalAppData%\Programs\WiClip` | без адміна | `HKCU\...\Run` — тільки в поточного |

Тихе встановлення:

```powershell
# для всіх користувачів (типово, потрібні права адміністратора)
msiexec /i WiClip-1.0.1-x64.msi /qn

# лише для поточного користувача, без прав адміністратора
msiexec /i WiClip-1.0.1-x64.msi /qn MSIINSTALLPERUSER=1
```

Інші варіанти:

```powershell
# без автозапуску, але з ярликом на робочому столі
msiexec /i WiClip-1.0.1-x64.msi /qn ADDLOCAL=Main,DesktopShortcutFeature

# у власний каталог
msiexec /i WiClip-1.0.1-x64.msi /qn APPLICATIONFOLDER="D:\Apps\WiClip"

# видалення
msiexec /x WiClip-1.0.1-x64.msi /qn
```

Склад компонентів: `Main` (обовʼязковий), `AutostartFeature` (автозапуск, увімкнений
типово), `DesktopShortcutFeature` (ярлик на робочому столі, типово вимкнений).

Оновлення встановлюється поверх — попередня версія видаляється автоматично, запущений
екземпляр закривається без перезавантаження.

Інсталятор **не підписаний сертифікатом**, тож Windows SmartScreen покаже попередження:
«Детальніше» → «Виконати в будь-якому разі».

## Де лежать дані

`%APPDATA%\WiClip\`:

- `settings.json` — налаштування;
- `history.json` — історія;
- `images\` — зображення з буфера;
- `wiclip.log` — журнал (обрізається по 512 КБ).

Видалення програми ці файли не чіпає — історію користувачів MSI не прибирає.
Щоб узагалі не писати історію на диск, зніміть у налаштуваннях галочку
«Keep history between sessions»: файли видаляються, історія живе лише в памʼяті.

**Важливо про безпеку:** історія зберігається у відкритому вигляді, як і у вбудованого
`Win+V`. На спільних і термінальних серверах враховуйте це — паролі, що випадково
потрапили в буфер, опиняться у файлі. Допомагають галочка «не запамʼятовувати буфер
менеджерів паролів» і режим «лише в памʼяті».

## Автозапуск

- Під час першого запуску WiClip прописує себе в автозапуск **поточного користувача**
  (`HKCU\...\Run`); вимикається в налаштуваннях.
- Компонент інсталятора `AutostartFeature` (увімкнений типово) додає запис у
  `HKLM\...\Run` при встановленні для всіх користувачів або в `HKCU\...\Run` при
  встановленні лише для себе. Якщо запис машинний, галочка в налаштуваннях показана
  увімкненою та заблокованою — зняти її можна лише з правами адміністратора.

## Відомі обмеження

- Вставка (`Ctrl+V`) не доходить до вікон, запущених **з правами адміністратора**,
  якщо сам WiClip працює без них — так влаштована ізоляція рівнів цілісності Windows
  (UIPI). Запису в буфер це не заважає: `Ctrl+V` можна натиснути вручну.
- Гаряча клавіша може бути зайнята іншою програмою — WiClip покаже сповіщення в треї,
  сполучення змінюється в налаштуваннях. `Win+V` зайнятий системною історією Windows,
  його брати не можна.
- З буфера зберігається простий текст; форматування (RTF/HTML) при вставці втрачається.

## Локалізація

Рядки інтерфейсу лежать у `src/WiClip/Resources/Strings.resx` (англійська — нейтральна
мова, потрапляє в основну збірку) та `Strings.ru.resx` (російська, окрема збірка-сателіт
`ru\`). `Strings.cs` — тонка типізована обгортка над `ResourceManager`, пошук завжди
йде за `CultureInfo.CurrentUICulture`.

Вибір мови робить `Localization.Apply()` до створення вікон: XAML читає
`{x:Static local:Strings.X}` один раз під час завантаження. Тому зміна мови в
налаштуваннях перестворює вікно історії та меню в треї.

Тексти інсталятора окремі: `installer/en-us.wxl` і `installer/ru-ru.wxl`, обираються
ключем `build.ps1 -Culture`.

Щоб додати українську (чи будь-яку іншу) мову інтерфейсу: додайте рядки в
`tools/gen-strings.py`, згенеруйте `Strings.uk.resx`, впишіть код у
`SatelliteResourceLanguages` в csproj, додайте пункт у список налаштувань і за бажанням
`installer/uk-ua.wxl` разом із її LCID у `build.ps1`.

## Структура проєкту

```
src/WiClip/
  App.xaml(.cs)          старт, іконка в треї, єдиний екземпляр
  HistoryWindow.xaml     вікно історії: пошук, список, вставка
  SettingsWindow.xaml    налаштування
  ClipboardMonitor.cs    приймання WM_CLIPBOARDUPDATE, фільтри приватності
  HistoryStore.cs        історія, дедуплікація, ліміт, збереження
  HotKeyManager.cs       глобальна гаряча клавіша (RegisterHotKey)
  Paster.cs              запис у буфер і надсилання Ctrl+V у цільове вікно
  Native.cs              P/Invoke
  Resources/Strings.resx    рядки інтерфейсу, англійська (нейтральна)
  Resources/Strings.ru.resx рядки інтерфейсу, російська (сателіт ru)
  Localization.cs        вибір мови інтерфейсу
installer/
  WiClip.wxs             опис MSI (WiX 5)
  en-us.wxl / ru-ru.wxl  рядки інсталятора
  License.rtf            текст ліцензії в інсталяторі
tools/gen-strings.py     генератор ресурсів локалізації
build.ps1                публікація + генерація списку файлів + збірка MSI
```
